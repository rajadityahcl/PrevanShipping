# PREVAN SHIPPING Dashboard

## Run locally in VS Code

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py` - Streamlit dashboard
- `requirements.txt` - Python dependencies
- `prevan_logo.png` - logo used in dashboard

## Features
- Editable operational inputs from sidebar
- Real-time comparison of 3 models
- KPI cards, charts, scenario table
- CSV download
